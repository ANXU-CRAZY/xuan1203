# 方舟科研工作台（本地前端集成）

入口：`http://127.0.0.1:8012/workbench/`。监测首页的应用菜单新增“科研工作台”。
使用方舟现有 Logo、主题色、字体与导航，并将真正的 GeoLibre Web 应用嵌入本地页面。

## 本地构建

先安装 Git 与 Node.js 22+，然后在项目根目录执行：

```powershell
.\anxu\Scripts\python.exe scripts/setup_geolibre.py
.\anxu\Scripts\python.exe scripts/configure_workbench_maps.py --amap-notebook "D:\gis工程\p5x.ipynb"
.\anxu\Scripts\python.exe manage.py runserver 127.0.0.1:8012 --insecure
```

GeoLibre 固定为 MIT 许可的 3.7.0 版，提交
`2a0df8c5f1542ef2d577f0fdc038df45a910da8a`。
原始代码放在 `var/geolibre/source/`，浏览器构建放在 `var/geolibre/dist/`，
均被 Git 忽略；构建目录可通过 Django 设置 `GEOLIBRE_WEB_ROOT` 覆盖。
嵌入 SDK 和 MIT 许可保留在工作台静态资源目录中。
构建采用相对资源路径并禁用 Service Worker，避免影响现有平台。

首次构建需要联网。底图和部分 GeoLibre 可选浏览器工具依赖外部地图/CDN；
这不是完全离线发行版。安装脚本会准备独立的空间计算依赖，平台首次调用时自动启动
仅监听本机的 GeoLibre 计算组件，使用者不需要手动启动它。计算组件位于
`var/geolibre/venv`，运算中间文件位于 `var/geolibre/jobs`，均不会提交到 Git。

小舟使用平台配置的 DeepSeek 规划并调用 GeoLibre 的矢量工具与 Whitebox 工具；
图层数据由平台计算组件处理，模型请求包含图层摘要和工具调用上下文。具体工具仍受
输入数据格式、依赖及其许可证约束。浏览器兼容模式仅提供有限的分析功能。
原生模式下 IDW 可以使用 Whitebox 输出 GeoTIFF；经纬度图层的插值距离和格网大小
按数据坐标单位计算，不能直接当作米，科研分析应使用合适的投影坐标系。
兼容模式下点 IDW 仍输出演示用 GeoJSON 网格。

## 已实现

- 方舟页头、平台导航、示例工程、研究区全览、GeoJSON 快捷导入、地图 PNG 导出。
- 操作按钮已并入顶部导航，删除整条工程栏；图层列表改为紧凑列表。
- 默认天地图电子底图，支持影像、空白底图、高德底图与天地图独立注记开关。
- 保留左侧原生“背景”图层及“更改背景”弹窗，在弹窗顶部增加天地图电子图、
  天地图影像图和高德地图三个常用预设。原有 OpenFreeMap、区域、月球、火星、
  空白背景和自定义 URL 均保留；取消右侧重复入口。
- 高德使用现有 Web 服务 Key 的静态地图能力，不将其冒充为 JavaScript SDK Key。
  地图图像角点做 GCJ-02 / WGS84 适配，MapLibre 512px 与 Leaflet 256px 的缩放级别分别处理；
  观测数据和本地文件坐标不修改。高德图像自带注记，选择高德时禁用单独注记开关。
- 导出按钮通过 GeoLibre 原生渲染状态判断地图是否就绪，避免在底图或图层未加载完时导出。
- GeoLibre 原生图层开关、透明度、样式、属性查看与本机工程保存。
- 默认中文、方舟主题色、首次使用说明及手机端布局。
- 示例工程的研究区、河流线和二十四个点位均为人工模拟数据，已在界面与图层中标识。
- 快捷导入支持二十 MB 以内 WGS84 GeoJSON，验证文件结构和坐标范围；
  其他格式使用原生“添加数据”菜单，具体支持情况由 GeoLibre 浏览器版决定。
- 页面、智能体与本机计算组件通过 Django 提供；没有新增业务数据库表或数据迁移。
- WebGL2 不可用时立即切换本地 Leaflet / Canvas 2D 兼容地图；GeoLibre 启动失败或十六秒未就绪时也会回退。
  等待过程中两秒后收起遮罩，避免整个页面长时间留白。兼容模式支持 GeoJSON、图层开关和透明度、工程保存和 PNG 导出。

## 地图配置

地图 Key 写入被 Git 忽略的 `var/geolibre/providers.json`，不写入新增源码。
该配置文件不能作为工作台静态文件下载。工作台的 `basemap.json` 是当前地图的样式资源，
使用 Key 生成浏览器所需的图层 URL；这些地图服务 Key 会按地图协议随浏览器请求发送给各自服务方。
服务端不代理外部图片、不读取真实监测数据，也不将私有业务数据传给地图服务。
高德静态图接口自带图像署名；页面和导出图片保留所选地图来源署名。

GeoLibre 增加一个范围很小的方舟浏览器消息桥，用于同源底图切换。
桥接文件在 `integrations/geolibre/ark-bridge.ts`，构建脚本会在兼容性 polyfill 之后加载它。
预设组件在 `integrations/geolibre/ark-basemap-presets.tsx`，构建脚本将其插入固定版本的
原生 `BasemapPickerDialog`，不替换背景图层或原有背景目录。
选择事件仅接收来自同源地图框架的消息；原生其他预设被选中后，停止高德的视口跟随，
避免新预设被旧的高德状态覆盖。

## 边界

本版不读取平台监测数据，不调用慧眼模型、报告下载、GeoLens 或数据库接口；
小舟任务会调用平台配置的 DeepSeek。
本地文件导入不上传至平台。内置模拟工程只用于验证交互，不能用于科研结论。
当前本地工作台不要求登录；后续接入真实私有数据时，应同时接入后端授权。
`deployment.json` 的能力和菜单限制只作为前端配置，不视为数据权限保护。

嵌入通信复用官方 `@geolibre/embed` 3.7.0，通过浏览器 `postMessage` 实现，
不属于平台业务 API；允许通信的来源限定为当前页面所在的确切源，不使用通配符。
嵌入页仅允许同源框架加载，静态路径限制在构建目录内，并阻止点文件和越界访问。

仅在本地运行，尚未推送、部署或修改线上服务。
