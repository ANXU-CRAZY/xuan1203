## 本次实现

- 复用 `config.settings.TDT_KEY`，地图使用天地图 Web Mercator 矢量底图及中文注记，地名检索使用天地图服务。现有 key 为浏览器类型，因此由浏览器请求地图，不使用会被拒绝的服务端瓦片代理。key 未复制进静态 JS。
- 项目虚拟环境安装并固定 `onnxruntime==1.20.1`。该环境中的 1.23.2 存在 Windows DLL 初始化错误；1.20.1 经本机模型加载和推理验证。NumPy 版本范围调整为兼容现有环境的 `>=1.24,<3`。
- 模型仍为原工程的 ONNX 和物种嵌入库：186 个物种，其中鸟类 118 个。首次慧眼请求加载模型，不在 Django 启动时加载。推理使用 CPU、2 个计算线程、并发锁。
- 修复后处理以 float16 计算像素面积造成溢出的问题。大图采用整图加四个重叠分块，再进行全局 NMS，输出坐标保持原图像素单位。返回明细上限为 150 个检测框。
- 五张用户提供的鸟类照片加入例图。白琵鹭 TIFF 同时保留原件及浏览器预览 JPEG；点击 TIFF 例图实际走转换接口，再走识别接口。其余例图也实际调用模型，不使用预设结果。
- 大体积 TIFF JSON 请求改为有大小上限的请求流读取，避免默认 2.5 MB 请求体限制。原图不持久化到服务端。
- 复用主站的 Inter、苹方、微软雅黑字体栈，品牌、正文、按钮及数字标签统一字体，副标题加粗至 700；采用浅色纸白、青绿配色、胶囊按钮，保留深色切换。手机优先显示识别和例图，并提供选择物种锚点。
