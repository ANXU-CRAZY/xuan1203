# 项目计划书正文

## 1、作品概述

**作品背景**

黄河流域是我国生态保护和高质量发展的重大国家战略区，沿黄湿地是东亚-澳大利西亚候鸟迁徙路线上的关键节点，承载着白枕鹤、大鸨、东方白鹳、黑鹳等珍稀水鸟的繁殖、栖息与越冬功能。然而，传统的湿地鸟类监测长期面临三个突出问题：一是观鸟数据分散在不同部门、不同保护区与不同志愿组织手中，缺乏统一的空间数据库；二是公众参与门槛高，巡护员手工填表、爱好者拍照随手发圈，数据无法回流到管理部门；三是物种知识、识别能力、管理后台与展示前端相互割裂，地图、图库、科普、AI 识别没有打通成完整的业务链路。

**选题动机**

我们希望面向黄河湿地这一具体生态场景，用 GIS 技术把"专业监测—公众上报—空间分析—智能识别—科普传播"做成一个统一的 Web 平台。GIS 不只是底图叠加，还应该是数据治理、空间分析与决策辅助的核心引擎。

**目的**

构建一套基于 GeoScene 平台的"黄河生态方舟"Web 应用系统，实现湿地区域、监测点位、监测样线、观鸟记录、物种知识、AI 识别记录的一体化空间管理与可视化分析，为湿地保护管理者提供工具，为公众参与生态保护提供入口。

## 2、需求分析

**应用领域**

- 自然保护区与湿地公园的鸟类监测与巡护管理。
- 林业、生态环境主管部门的生物多样性数据汇集与展示。
- 高校、中小学和科普场馆的生态教育与公众科普。
- 观鸟协会、志愿者组织的众包数据采集与协同。

**实用性分析**

1. 管理端实用性。系统提供基于 GeoScene Server 的空间数据发布与管理能力，管理员可在 GeoScene Pro 中维护湿地边界、监测点位、监测样线等矢量数据，发布为 Feature Service / Map Service，再通过 Web 端进行编辑、审核与统计，告别 Excel + 纸质表格的传统模式。

2. 巡护端实用性。巡护员和观鸟爱好者可以通过浏览器或移动浏览器，定位当前位置、选择物种、上传照片，记录直接进入空间数据库，并按经纬度落到地图上，由管理员在后台审核入库。

3. 分析端实用性。系统支持时间维度筛选、图层叠加、矩形/多边形圈选、热力分析、缓冲区附近预警等空间分析功能，使观鸟数据真正变成"可分析的地理数据"。

4. 科普端实用性。物种百科、鸟类图库、科普文章和互动小游戏面向公众用户，使生态保护从"少数专业人员的工作"扩展为"全民参与"。

5. AI 端实用性。集成水鸟图像识别模型（YOLO 检测 + 分类双模型），上传一张鸟类照片即可定位鸟体并给出物种判别，用于辅助新手识鸟和巡护现场速查。

6. 推广实用性。整套作品已部署在公网（http://8.130.88.229），具备真实可访问性、可演示性和可扩展性，能直接服务于黄河沿线的湿地公园、保护区与高校实习基地。

## 3、功能设计概述

### 3.1 系统架构图

```text
                         ┌──────────────────────────────────────────┐
                         │         浏览器 / 移动端浏览器            │
                         │   生态大屏 / 上报 / 百科 / 图库 / 识别   │
                         └──────────────────┬───────────────────────┘
                                            │ HTTPS
                         ┌──────────────────▼───────────────────────┐
                         │           Nginx 反向代理 + 静态托管      │
                         └─────────┬───────────────────┬────────────┘
                                   │                   │
                  ┌────────────────▼─────┐   ┌─────────▼──────────┐
                  │   GeoScene Server    │   │   Gunicorn + Django │
                  │  Feature/Map Service │   │     业务 API 层     │
                  │  GeoProcessing 服务  │   │   (DRF + GIS API)   │
                  └────────┬─────────────┘   └─────────┬──────────┘
                           │                           │
                           │   ┌───────────────────────┘
                           ▼   ▼
                  ┌──────────────────────┐
                  │   PostgreSQL 16      │
                  │      + PostGIS 3     │
                  │  物种 / 点位 / 样线  │
                  │  观测 / 图库 / 用户  │
                  └──────────┬───────────┘
                             │
                             ▼
                  ┌──────────────────────┐
                  │  AI 模型与媒体资源   │
                  │  YOLO 检测/分类模型  │
                  │  observation 影像库  │
                  └──────────────────────┘
```

总体上采用 B/S 架构。GIS 空间服务由 GeoScene Server 发布，业务逻辑、用户、积分、上报与 AI 识别由 Django + DRF 后端处理，二者通过统一的 PostgreSQL/PostGIS 空间数据库联通；前端基于 GeoScene Maps SDK for JavaScript 加载底图与业务图层，并叠加业务弹窗、热力分析与统计图表。

### 3.2 功能模块描述

| 编号 | 模块 | 主要功能 |
|---|---|---|
| M1 | 生态大屏与地图监测 | 加载天地图与 GeoScene 影像底图，叠加湿地区域、监测点位、监测样线、观鸟记录矢量瓦片；支持图层切换、时间筛选、记录弹窗、保护等级占比图表 |
| M2 | 空间分析模块 | 支持矩形/多边形圈选、南北向最小外接矩形热力图、附近 500 m 观鸟预警、观测点缓冲区分析 |
| M3 | 公众上报模块 | 提供 Web 与移动浏览器的鸟类观测上报入口，自动获取经纬度，支持物种、点位、数量、图片、描述字段 |
| M4 | 后台审核模块 | 管理员对公众上报记录进行审核（pending / approved / rejected），审核通过后进入展示数据池 |
| M5 | 物种百科与图库 | 物种中文名、拉丁名、目科、保护等级、IUCN 状态、分布习性、封面图、图库图片、相关观测计数 |
| M6 | 科普文章模块 | 湿地保护、物种科普文章发布与浏览，支持浏览量统计 |
| M7 | AI 水鸟识别模块 | 基于 YOLO 检测 + 分类双模型对上传图片进行鸟体定位与物种判别，支持检测阈值与分类阈值参数 |
| M8 | 用户与积分模块 | 注册、登录、Token 鉴权、积分获取、商品兑换、个人头像、个人资料 |
| M9 | 互动游戏模块 | 看图识鸟、迁徙、湿地修复、湿地侦探、飞鸟跑酷、浮岛等互动小游戏，用于公众科普 |
| M10 | 数据导入与维护 | 通过 Django Management 命令完成 SHP 导入、物种元数据同步、Wikimedia 图片回填、保护等级标准化、地图缓存刷新等数据治理任务 |

## 4、作品运行环境

| 体系结构 | B/S（Browser/Server）三层架构：浏览器前端 + 应用服务层 + 空间数据库层；GIS 服务通过 GeoScene Server 发布 |
|---|---|
| 开发平台 | Windows 10/11（开发）、Ubuntu 22.04 LTS（部署） |
| 开发工具 | GeoScene Pro 3.x（数据建库与服务发布）、PyCharm Professional、Visual Studio Code、Git/GitHub、Postman、DBeaver、QGIS（数据校核）、Nginx、Gunicorn |
| 开发语言 | Python 3.11（后端、AI 推理、数据治理脚本）、JavaScript ES2020、HTML5、CSS3（前端）、SQL/PL-pgSQL（空间查询）、Shell（部署脚本） |
| 运行环境 | 服务端 Ubuntu 22.04 LTS + Nginx 1.24 + Gunicorn 21 + Python 3.11；客户端支持 Chrome、Edge、Firefox 等主流浏览器及 iOS/Android 移动浏览器；公网示例地址 http://8.130.88.229 |
| 数据库 | PostgreSQL 16 + PostGIS 3.4 空间扩展，存储物种、湿地区域、监测点位、监测样线、观测记录、图库、用户、AI 识别历史等业务表 |
| GIS 平台 | GeoScene Server 11.x（Feature Service / Map Service / GeoProcessing Service）、GeoScene Pro 3.x（建库与发布）、GeoScene Maps SDK for JavaScript 4.x（前端地图渲染）、GeoScene Online（底图与底图配色服务） |
| AI 框架 | PyTorch 2.x + Ultralytics YOLO（detector.pt 鸟体检测、classifier.pt 物种分类） |
| 主要后端依赖 | Django 5.2、Django REST Framework 3.16、djangorestframework-gis 1.2、django-leaflet、django-cors-headers、django-import-export、Pillow、psycopg2-binary |
| 其他（可扩充） | 矢量瓦片接口（Mapbox Vector Tile）、Token 鉴权、Wikimedia Commons 图片回填、Shapefile 批量导入、地图观测缓存预生成命令、SimpleUI 后台美化 |
