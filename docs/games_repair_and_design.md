# 六个生态小游戏：修复与界面整理

日期：2026-11-08。适用本地 Django 项目；本次未执行线上部署。

## 排查与修复

排查时六个本地页面均返回 HTTP 200，监测大屏菜单也能跳转。发现并处理了以下会导致加载等待、空题目或初始化中断的问题：

- 五个 Canvas 游戏在页面头部同步请求外部 jQuery。网络阻塞时，备用脚本也需要等待外部请求失败才能运行。现六个游戏均使用项目内的 jQuery、图标及系统字体，无开场必需的 CDN 请求。
- 看图识鸟使用完整物种序列化接口；该接口逐物种查询观测统计，而游戏不需要这些统计。新增 `/api/games/birds/`，通过两条数据库查询读取物种与图片，不查询观测表，并排除本地文件已缺失的图库记录、无照片物种及外链照片。
- 图库加载改为页面内状态提示，8 秒超时，提供重新加载按钮，不再用全屏遮罩挡住页面。照片加载失败时禁用答案，允许重试；答题前必须实际显示照片。
- 湿地侦探同样使用轻量图库，5 秒超时后仍可用原内置线索数据进入调查。
- 存储受限时使用会话内临时存储；湿地修复师的损坏 JSON 进度不会导致初始化异常，关卡数和总分有数值回退。
- 湿地修复师移除了重复的空格监听，按一次仅切换一个工具；移动方向键不再让网页跟着滚动。
- 修正侦探开场时间说明为实际使用的 90 秒；浮岛开场数量与滑块保持同步；识鸟难度卡说明连击另加分，避免“满分”与实际总分不符。

游戏题库仅使用真实存在的图库文件；未下载替代图片，也未用模拟图片凑题目。当前本机可用 293 个物种、367 张照片，这些数字由接口计算。

## 设计方向

使用 [unslop](C:/Users/Xuan/.codex/skills/unslop/SKILL.md)，由 Damir Sokolovsky（[@heydamir](https://x.com/heydamir)）创作，CC BY 4.0。

- 产品：黄河湿地中的鸟类学习、飞行挑战、生态修复与调查小游戏。
- 气质：亲近自然、清楚、可操作，每个游戏保留自己的主题。
- 场景：照片图鉴、草地飞行、蓝绿湿地、夜航天空、纸色调查档案及湖面浮岛。
- 视觉重点：真实鸟类照片、原游戏 Canvas 场景和鸟类预览；浮岛使用与搭建玩法相关的植物木筏 SVG。
- 识别细节：页头沿用各游戏名称与主题图标，操作面板只保留有意义的选中和状态反馈。

| 游戏 | 保留的风格 | 主要整理 |
| --- | --- | --- |
| 看图识鸟 | 自然绿、照片图鉴 | 本地照片预览、图像等比完整显示、难度选择、答题与科普区层级 |
| 小鸟闯关 | 草地绿、轻松飞行 | 白色鸟类加轮廓线、可键盘选择的角色卡、选中反馈与操作说明 |
| 湿地修复师 | 蓝绿湿地、任务工具 | 选关、修复指标、生态链工具与文字对比度 |
| 候鸟迁徙记 | 深蓝夜空、金色动作 | 选鸟卡、体力/速度/灵活指标、可展开科普；手机端开始按钮可见 |
| 湿地侦探 | 纸色、棕色调查档案 | 调查参数、线索与选项、科普卡；照片完整显示 |
| 生态浮岛 | 湖水青、自然搭建 | 木筏植物预览、数量设置、材料栏与生态指标 |

九项整理分别覆盖间距、主题内配色、图标、文案、字级、布局、控件细节、真实内容与动效。减少厚重阴影、发光、无意义装饰和反复摆动；保留游戏场景中的色彩、运动、计分、选关和原有规则。支持减少动态效果的系统设置。
