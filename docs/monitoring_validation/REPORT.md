- 年份来自当前保护筛选下的真实有效、已审核记录；日期筛选不会把可用年份列表缩成当前年份。播放等待数据与圈选热力统计完成，再推进下一帧；暂停、请求取消、序号和筛选条件校验防止旧响应覆盖。无年份禁用，单年份播放一次后停止。
- 观鸟记录与保护专题共用原版记录图层，默认打开。低缩放全量聚合；14 级起按视域显示真实点，每页最多 5,000 条，以 `after` 游标手动加载下一页。后台先筛选再聚合或分页。密集区域分页期间保留覆盖全部记录的背景聚合，中文图例分别显示记录、鸟只、物种和分页提示。
- 完整统计直接查询 `ObservationRecord`、`SpeciesInfo` 与 `WetlandZone`，审核或物种等级变化不会因首页缓存滞后而泄露未审核记录或使用旧等级。坐标依次采用记录几何、记录经纬度、区域几何、区域经纬度。详情保留缓存中的原样线名称。

- 缓冲默认 500 米，范围 50—10,000 米；`ST_DWithin(...::geography)` 按米查询，显示 PostGIS 生成的缓冲面。记录受日期与保护筛选约束。有效样线按空间距离查询；原样线模型没有日期、保护等级字段，不虚构这些属性。样线统计完整，图形最多展示 100 条并返回截断标志。
