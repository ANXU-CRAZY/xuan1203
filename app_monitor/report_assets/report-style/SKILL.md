# 数据与编排

章节按监测概况、时序变化、物种与保护等级、方法与口径、后续监测建议组织。参考用户提供的 2024 年及 2025 年监测报告的章节逻辑，不复用其中的调查规模、路线、人员、工具或历史结论作为本期事实。

数据以服务器汇总为准。观测条数、观测只次、去重物种数和点位数分别标示。同比使用上年对应日历时段，未结束的年度或月份截至生成日。基期为零时不计算百分比。不要将观测只次描述为独立个体数或区域种群总量。

# DeepSeek 写作

调用相邻的 `../deepseek_editor.md` 作为运行时系统提示词，只发送汇总数据。启用 JSON 输出，使用低温度，三个主题分别生成两个完整段落，验证键名和段落长度，不接受模型输出的数字。运行时提示词已融入 nature-writing 的结果与讨论分工、证据边界、替代解释和可执行建议规则。模型不可用或输出不合格时采用同样结构的确定性研判段落。此为提示词与验证规则，模型权重没有经过微调。

# 图像

统计图根据每次请求的数据重新绘制，不使用生成式模型绘制数值或坐标。图形组合包括时序对照折线图、各时段记录点位数柱形图、物种排序横向条形图、保护等级只次环形图、保护等级物种数横向条形图和 Word 原生表格。统计图采用克制的彩色配色，相同保护等级在不同图中使用相同颜色，原生表格为黑色三线表。标题和图表题均为黑体黑色，正文为小四号仿宋_GB2312，首行缩进两个字符，1.25 倍行距。表题在表格上方，图题在图下，图表各自连续编号，并在正文先引用再出现。物种图直接标注物种名，图注说明统计单位。正文连续排版，章节随内容自然分页，避免强制分页造成大面积留白。

综合分析结合观测峰值和记录点位覆盖、主要物种的只次与记录条数占比、重点保护物种数与只次结构，以及两期单条记录均值和点位数展开。数值由服务器计算，解释随当前数据变化，明确提出需要回查的记录与材料。点位数不等同于调查工作量，物种数接近也不能证明物种组成稳定。

封面插画使用已生成并随项目打包的 `../wetland-cover.png`，每份报告嵌入同一批准资产，并注明“AI 生成示意图”。不将插画作为实地照片或物种鉴定依据。更新插画时，提示词采用黄河湿地、沙洲、芦苇、远景鸟群及克制的矿物青与暖砂色，无文字、无标志，不让生图服务承担校徽绘制。

# 品牌与复核

页眉最左侧按用户原文写“郑州大学地球科学与技术学院·郑州市自然事物地保护中心·方舟实验室”，最右侧使用项目方舟 logo。封面不另加“黄河生态方舟”字样，页脚采用“鸟类监测报告”与页码。封面说明写“本报告由黄河生态方舟平台小舟智能体生成，供监测工作参考和人工复核。”正文和表格可编辑，图表以图片嵌入，附录包含完整物种汇总清单。导出不含记录或中心坐标、点位名称、自由描述。生成后检查空数据、部分周期、闰年、长物种名称、模型超时及小屏下载操作。
